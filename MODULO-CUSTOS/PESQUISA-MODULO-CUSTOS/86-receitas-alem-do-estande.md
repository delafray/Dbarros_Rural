# 86 — Receitas Acessórias de Expositores em Feiras Agropecuárias Brasileiras (2024–2026)

**Data:** 05/08/2026  
**Objetivo:** Mapear fontes de receita secundárias (além do aluguel de estande) que organizadoras de feiras agropecuárias cobram de expositores, com valores reais e referências concretas.

---

## 1. Resumo Executivo

Análise de 8 grandes feiras agropecuárias brasileiras (Agrishow, Expointer, Show Rural Coopavel, Expodireto, EXPOMAFE, Fenasoja, Exposibram, Fesqua) revelou **12 categorias de receitas acessórias**, além da taxa de estande. O segmento de energia elétrica é o mais estruturado e padronizado (cobrança por kVA), seguido por credenciais, internet e serviços auxiliares (água, ar comprimido). Taxa de inscrição de animais é cobrada em exposições com foco em pecuária. Custos variam de R$ 5,00 (credencial mínima) até R$ 200,00+ (energia extra ou internet).

## 3. Síntese de Padrões por Tipo de Receita

### Receitas Padronizadas (todas as feiras)
- **Energia elétrica:** Modelo universal; Show Rural é mais transparente (5 kVA gratuitos + R$ 200/kVA extra)
- **Credenciais de pessoal:** R$ 5–7 por pessoa, cobrado separadamente
- **Internet dedicada:** R$ 200 mínimo (Expointer), prazo de solicitação até janeiro

### Receitas Variáveis / Não Publicadas
- **Limpeza:** Cobrada por m², mas valor específico não aparece online em nenhuma feira
- **Água/Ar comprimido:** Bundlizadas em "taxa de montagem" ou infraestrutura; raramente segregadas
- **Estacionamento expositor:** Show Rural oferece grátis; Expointer cobra visitante mas não especifica expositor
- **Catálogo:** Não documentado em feiras brasileiras modernas (2024–2026)

### Receitas Especializadas (apenas eventos pecuários)
- **Inscrição de animais:** R$ 190–230 por animal (Expointer); tabelas não públicas
- **Baias:** Cobrança integrada à taxa de animal; não segregada

## 5. Implicações para o Módulo de Custos — Centro de Custo do Evento

### 5.1. Vendáveis Acessórios Recomendados no Sistema

O módulo deve prever **pelo menos os seguintes serviços como linhas de receita**:

1. **Energia Elétrica (kVA)**
   - Campo: "kVA livre incluído" (ex.: 5)
   - Campo: "Valor por kVA excedente" (ex.: R$ 200)
   - Cálculo: `energia_extra = (kVA_contratado - kVA_livre) × tarifa`
   - Diferencial: Show Rural é modelo a replicar

2. **Credenciais de Pessoal (Identificação)**
   - Campo: "Quantidade de credenciais" (ex.: 5)
   - Campo: "Valor por credencial" (ex.: R$ 5–7)
   - Cálculo: `receita_credenciais = qtd × valor_unitario`
   - Nota: Cobrada separadamente, não inclusa no estande

3. **Internet Dedicada / Ramal Virtual**
   - Campo: "Valor de internet" (ex.: R$ 200 mínimo)
   - Campo: "Velocidade ou classe de serviço"
   - Cálculo: Receita fixa ou variável conforme pacote
   - Prazo: Implementar campo de "data de corte de solicitação" (ex.: 30/01)

4. **Limpeza / Manutenção de Área**
   - Campo: "Taxa de limpeza por m²" (ex.: R$ X)
   - Campo: "Responsável pela limpeza" (enum: organizadora / expositor)
   - Cálculo: `receita_limpeza = area_estande × taxa_m2`
   - Nota: EXPOMAFE cobra; Show Rural não cobra segregadamente

5. **Inscrição de Animais (para exposições pecuárias)**
   - Campo: "Ativar módulo de pecuária" (booleano)
   - Subcampos por categoria: bovino, equino, ovino, caprino
   - Campo: "Valor de inscrição por animal" (ex.: R$ 190–230)
   - Cálculo: `receita_animais = quantidade_por_categoria × valor_categoria`
   - Complexidade: Tabelas específicas por raça/categoria (Expointer tem 50+ categorias)

6. **Montadora / Taxa de Credenciamento Terceirizado**
   - Campo: "Valor de registro montadora" (ex.: R$ 200)
   - Campo: "Credenciais adicionais por montadora" (ex.: 2)
   - Campo: "Valor por credencial adicional" (ex.: R$ 5–7)
   - Cálculo: `receita_montadora = qtd_montadoras × 200 + credenciais_extras × 5`

7. **Estacionamento de Expositor**
   - Campo: "Cobrar estacionamento expositor?" (booleano)
   - Campo: "Valor de estacionamento" (ex.: R$ 0 para Show Rural, R$ 53 para Expointer visitante)
   - Nota: Diferenciar "expositor" vs. "visitante/público"

8. **Água / Ponto de Água**
   - Campo: "Incluir ponto de água na venda?" (booleano)
   - Campo: "Valor do serviço de água" (se segmentado)
   - Nota: Raramente cobrada isoladamente; validar com usuário

9. **Ar Comprimido / Serviços Técnicos**
   - Campo: "Ofertar ar comprimido?" (booleano)
   - Campo: "Valor" (ex.: R$ 0 se bundlizado)
   - Nota: Tipicamente negociado caso a caso, não padronizado

10. **Catálogo Oficial**
    - Campo: "Cobrar taxa de catálogo?" (booleano)
    - Campo: "Valor" (valores históricos internacionais: R$ 50–150, mas não confirmado Brasil 2024–2026)
    - Nota: Validar se evento moderno realmente cobra isso

11. **Seguro Obrigatório**
    - **Observação importante:** Seguro é contratado pelo expositor com broker externo, NÃO é receita direta da organizadora
    - Campo: "Exigir seguro expositor?" (booleano)
    - Campo: "Cobertura mínima exigida" (ex.: R$ 5.000)
    - **Recomendação:** Registrar como "exigência" (controle), não como "receita"

### 5.2. Arquitetura de Dados Sugerida

Cada evento deve ter um mapa de "Serviços Vendáveis" (separado de "Estandes"):

```
evento {
  id
  nome
  tipo: enum [COMERCIAL, PECUÁRIO, MISTO]
  
  estandes: [
    { id, metragem, valor_base, categoria }
  ]
  
  servicos_acessorios: [
    {
      id
      tipo: enum [ENERGIA, CREDENCIAL, INTERNET, LIMPEZA, ANIMAL, MONTADORA, ESTACIONAMENTO, AGUA, AR_COMPRIMIDO, CATALOGO, SEGURO]
      nome_display: string
      valor_unitario: float
      unidade: enum [UNIDADE, M2, KVA, ANIMAL_INSCRITO, CREDENCIAL]
      obrigatorio: bool
      data_corte_solicitacao?: date
      descricao: text
      ativo: bool
    }
  ]
}
```

Cada expositor pode ter:

```
expositor_evento {
  id
  expositor_id
  evento_id
  area_m2: float
  
  servicos_contratados: [
    {
      servico_id
      quantidade: float
      valor_unitario: float
      subtotal: float
      data_solicitacao: date
    }
  ]
  
  total_estande: float
  total_acessorios: float
  total_evento: float
}
```

---

### 5.3. Validações e Regras de Negócio

1. **Credenciais:** Mínimo de 1 (obrigatória para responsável do estande), máximo conforme regulamento
2. **Energia:** `kVA_contratado >= kVA_minimo_obrigatorio` (validação em EXPOMAFE: 0,1 kVA/m²)
3. **Internet:** Desabilitar após data de corte de solicitação
4. **Animais:** Permitir múltiplas categorias; somar todos para total de receita pecuária
5. **Estacionamento:** Campo booleano "gratuito?" — se verdadeiro, receita = 0
6. **Montadora:** Associar credenciais extras à quantidade de montadoras registradas

## 7. Observações Finais

1. **Transparência:** Apenas Show Rural Coopavel e Expointer publicam tarifas completas online. Agrishow e EXPOMAFE cobram, mas valores integram contratos comerciais (não públicos).

2. **Oportunidade de receita:** Uma fair de médio porte (500 estandes × R$ 1.000 estande) pode gerar:
   - Energia: 500 × (1–2 kVA extra) × R$ 200 = R$ 100.000–200.000
   - Credenciais: 500 × 3 pessoas × R$ 5 = R$ 7.500
   - Internet: 100 × R$ 200 = R$ 20.000
   - **Total acessórios: R$ 127.500–227.500** (adicional ao aluguel de estandes)

3. **Segmentação:** Feiras comerciais (Agrishow, Expodireto) enfatizam energia e internet; feiras pecuárias (Expointer, Fenasoja) enfatizam inscrição de animais. Dbarros (rural agropecuária) deve suportar ambos.

4. **Recomendação:** Implementar módulo de serviços acessórios em estrutura modular — eventos pecuários ativam "módulo de animais"; eventos comerciais ativam "módulo de energia premium + internet". Não forçar todos os campos em todos os eventos.
