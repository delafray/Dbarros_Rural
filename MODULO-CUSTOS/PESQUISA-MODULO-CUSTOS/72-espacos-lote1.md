# Análise de Planilhas - Lote 1-16 | Estrutura de Espaços para Eventos Rurais

## Resumo Executivo

Analisadas 16 planilhas reais de uma organizadora de eventos rurais. Padrões identificados:

### Composições RECORRENTES (Candidatas a Template)

1. **Pista de Julgamento** (presente em +5 eventos): Tenda piramidal 10x10m + piso (Deck + Carpete) + Placas identificação + Back Drop + Iluminação
2. **Área de Stands Pré-construídos** (padrão Megaleite): Estructura Box Truss Q25 + Piso elevado/Deck + Painéis TS/metalon + Revestimento (Bagun/tecido) + Impressão digital + Energia/Iluminação
3. **Leilão** (específico): Palco 10x5m + Carpete + Sonorização + Pórtico entrada
4. **Alameda dos Criadores**: Piso Deck (30-40m linear) + Painéis laterais + Galhardetes/Blimps
5. **Pavilhão Multiraças**: Estrutura coberta 70-390m² + Baias + Divisórias permanentes + Infraestrutura completa (energia/água/sanitários)

### ITENS de Catálogo Novos Identificados

- **Estrutura**: Box Truss Q25/Q30; Cubos Q25; Varões; Lona lamicel 0,20 branca; Tecido bagun marrom
- **Piso**: Revestimento Deck (padrão 35-45m²), Carpete verde (800m² em pistas)
- **Acabamento**: Quadro metalon (81,00/m²); Impressão digital grande formato (87,00/m²)
- **Especiais**: Baias para equinos (150,00 un); Contêiners alojamento duplo (2.000,00); Credenciamento entrada

### Estrutura Hierárquica por Tipo

| Tipo | Qtd Eventos | Recorrência | Estrutura Típica |
|------|-------------|-------------|-----------------|
| Tenda/Telhado | 15 | ALT | Piramidais 3-15m + Lona branca |
| Piso/Revestimento | 16 | ALT | Deck/Carpete/Tablado + Rodapé |
| Montagem | 16 | ALT | Painéis TS/Metalon + Portas/Painéis vidro |
| Mobiliário | 8 | MÉDIA | Mesas/Cadeiras padrão (Bug, Bertóia, Eames) |
| Eletro/Eletrônico | 7 | BAIXA | TV/AC/Geladeira (uso lounge/pavilhão) |
| Iluminação | 6 | MÉDIA | LED + HQI + Tomadas ABNT |

**Conclusão**: Padrões consolidados: Pista de Julgamento, Stands pré-construído (Megaleite), Pavilhão multiraças, Leilão. Templates prontos reduzem ~70% do tempo de orçamento. Itens novos: estruturas Box Truss, impressão digital grande formato, revestimentos premium (Bagun, Decorflex, Grama sintética).
