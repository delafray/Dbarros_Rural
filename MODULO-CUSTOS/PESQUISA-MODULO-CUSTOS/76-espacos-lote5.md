## Padrões Recorrentes (Templates Candidatos)

### Padrão A: "Pavilhão Base"
- **Composição**: Piso elevado (tablado) + revestimento deck + rodapé + Box Truss Q25 + iluminação
- **Escalas**: 60m² (credenciamento) → 268m² (alameda) → 931m² (choperia)
- **Itens catálogo**: Tablado, Deck, Rodapé madeira, Box Truss Q25, Cubos Q25, Tomadas ABNT, Refletores
- **Frequência**: 6/16 planilhas (alameda, choperia, stands, credenciamento, pré-construídos ×2)

### Padrão B: "Pórtico/Portal"
- **Composição**: Estrutura Box Truss + Cubos + Revestimento napa/bagun + Impressão digital 41-56m²
- **Escalas**: Pequeno (13m² imp.) → Grande (41,5m² imp.)
- **Itens**: Box Truss Q25 (26-55m), Cubos Q25 (6un), Lona lamicel, Varões, Revestimento
- **Frequência**: 5/16 (pórticos alameda, pista, tartesal ×2, placas pista)

### Padrão C: "Lounge Elevado"
- **Composição**: Piso deck/carpete muito grande + Guarda-corpo + Balcões madeira + Iluminação especial
- **Escalas**: 557m² (stands) a 931m² (choperia)
- **Itens**: Piso elevado (2 tipos), Guarda-corpo 24-153m, Bancadas, TV, Ar-condicionado
- **Frequência**: 2/16 (choperia, lounge stands) — **específico a alto padrão**

### Padrão D: "Sala Fechada"
- **Composição**: Piso pequeno + Painéis TS + Portas blindex + Teto sarrafo + Ar-condicionado
- **Escala**: ~90m²
- **Itens**: Tablado 87,75m², Painéis TS (15un), Portas blindex (2), Teto sarrafo, AC Split 18k
- **Frequência**: 1/16 (sala reunião) — **específica funcional**

### Padrão E: "Tenda Modular"
- **Composição**: Tenda piramidal + Fechamento lateral + Porta + Painéis + Pia
- **Escala**: 5×5m (tenda padrão)
- **Itens**: Tenda piramidal, Fechamento (3un), Porta alumínio, Painéis TS, Pia com bancada, Balcão TS
- **Frequência**: 1/16 (posto médico) — **específica médica**

## Composições Específicas × Recorrentes

### Recorrentes (80% confiança para templating)
1. **Pavilhão Elevado**: Tablado + Deck + Box Truss + Iluminação padrão
2. **Pórtico Básico**: Box Truss + Revestimento napa + Impressão 40-50m²
3. **Sinalização Externa**: Quadros metalon + Impressão digital (padrão 1,8×1,1m)

### Específicas (não replicar sem ajuste)
- Lounge com guarda-corpo longo (153m) — design de pista única
- Sala climatizada (raridade; apenas 1 evento)
- Tenda médica (fins únicos)
- Blimps infláveis (decoração não-estrutural)

## Conclusões para Templates

**3 templates mínimos:**
1. **"Pavilhão Elevado Padrão"** (60–930m², piso + Box Truss + iluminação)
2. **"Pórtico Promocional"** (Box Truss + revestimento + impressão digital)
3. **"Espaço Social"** (piso elevado + guarda-corpo + lounge ligero)

Catálogo de itens críticos: Tablado, Deck, Box Truss Q25, Cubos, Quadros metalon, Impressão digital, Balcões TS, Iluminação refletor HQI.

Evento Megaleite 2022 é **referência funcional completa** para eventos rurais multi-espaço.
