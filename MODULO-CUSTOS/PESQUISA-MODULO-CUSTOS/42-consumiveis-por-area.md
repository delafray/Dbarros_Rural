# Consumíveis e Materiais "de Subsolo" por Área — Kit de Almoxarifado do Evento

> **Data:** 2026-08-02
> **Objetivo:** Fornecer a camada abaixo do "item principal". Já temos ~45 áreas mapeadas em nível de macroitem (estrutura, elétrica, som, shows, julgadores, peões, animais, legal, banheiros, limpeza, segurança, manutenção, RH, caixas, bilheteria, estacionamento, internet, VIPs, divulgação, praça de alimentação, torneio leiteiro, montagem/desmontagem etc.). Falta o **almoxarifado**: materiais, consumíveis, acessórios e taxas pequenas que "todo mundo esquece" e que estouram o caixa no dia do evento.
> **Uso pretendido:** quando o usuário **ticar uma área** no sistema, sugerir automaticamente o "kit de consumíveis" correspondente (lista transversal abaixo), já com unidade de medida para orçar quantidade.
> **Método:** varredura de checklists de produtoras (event supplies / almoxarifado de evento), catálogos de fornecedores BR de limpeza, elétrica e sinalização, e listas de "kit de sobrevivência do produtor". Fontes ao final.

---

## Como ler esta lista

- Cada bloco = uma **área** que já existe no módulo.
- Coluna **Item** = o consumível/acessório de subsolo.
- Coluna **Un.** = unidade de medida sugerida para o campo de quantidade (un, cx, rolo, m, L, pct, par, kg, fardo).
- Itens marcados **[reserva]** são estoque de contingência (o produtor sempre leva a mais) — o sistema pode sugerir um % sobre o principal.
- Itens marcados **[taxa]** são pequenas taxas/custos administrativos que passam batido.

Nada aqui substitui o macroitem; é o **complemento consumível** dele.

## Regras sugeridas para o sistema (automação do kit)

1. **Ticou a área → sugere o bloco correspondente** desta lista como itens candidatos (o usuário aceita/edita quantidade).
2. **Itens transversais** (fita isolante, abraçadeira, saco de lixo, silver tape, pilhas, EPI de visitante, água/copo do staff) aparecem em **mais de uma área** — no banco, tratar como itens de catálogo reutilizáveis, não duplicar cadastro.
3. **Marcadores `[reserva]`** → sugerir quantidade como **% do item principal** (ex.: 10% de lâmpadas/disjuntores/lona a mais).
4. **Marcadores `[taxa]`** → lançar como custo recorrente/diária (combustível de gerador, gelo, descarga de sucção, locação de escada), não como material de estoque.
5. **Unidade de compra vs. unidade de consumo**: saco de lixo, luva e copo compram-se em fardo/caixa mas consomem-se por unidade — o campo Un. acima já reflete a unidade de **compra** para orçamento.
